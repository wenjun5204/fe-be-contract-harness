# 任务拆分与粒度标准

## 粒度标准

- 每个任务 0.5~1 天可完成
- 单一职责:一个任务只改一个模块 / 一组契约端点
- 可独立测试:有明确验收(单测 / 契约测试)
- 依赖清晰:可拓扑排序

## 拆分方法

1. 按契约端点组拆(每个资源一组 CRUD)
2. 前后端分离(后端实现 vs 前端实现是独立任务,可并行)
3. 每个任务含 TDD 要求(先写测试再实现)

## 正反例

| 反例 ❌ | 正例 ✅ |
|---------|---------|
| 实现整个订单模块 | 实现 createPetOrder 后端 Controller + DTO + 单测 |
| 前端页面 + 后端接口一起做 | 后端接口 / 前端请求层 拆成两个并行任务 |

## 产出字段

每个任务:`{ id, 内容, 依赖[], 技术栈, 产出, 验收 }`
