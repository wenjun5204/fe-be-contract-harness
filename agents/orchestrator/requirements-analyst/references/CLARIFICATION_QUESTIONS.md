# 澄清问题库(按类别)

## 功能范围
- MVP 需要哪些功能?哪些可延后?
- 是否有权限 / 角色区分?
- 是否需要后台管理界面?

## 用户角色
- 谁会使用?是否有游客 / 未登录场景?

## 业务规则
- 关键业务规则是什么?(价格计算、库存扣减、状态流转)
- 异常情况如何处理?(库存不足、重复提交、超时)

## 边界
- 数据量级、并发量?
- 是否需要多端(Web / H5 / App)?

## 优先级
- 哪些是 P0(必须上线),哪些可迭代?

## 提问原则

1. 每批 ≤5 个,给选项而非开放式提问
2. 只问**影响契约字段 / 边界 / 错误码**的问题(这些会映射到 OpenAPI)
3. 技术实现细节不问(留给技术方案阶段)
4. 低影响决策不问(直接假设并记录)
