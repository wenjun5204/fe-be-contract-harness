# PRD 模板

> 标题层级从 `##` 开始(`#` 保留给文档标题)。填写后删除本行提示。

## 1. 概述

### 1.1 背景
当前存在什么问题 / 机会。

### 1.2 目标
- 业务目标(可量化)
- 用户目标

### 1.3 成功指标

| 指标 | 目标值 |
|------|--------|
| 如:需求交付后转化率 | +X% |

## 2. 用户分析

### 2.1 目标用户
- 主要用户、使用场景

### 2.2 用户痛点
- 痛点 1
- 痛点 2

## 3. 功能需求

### 3.1 功能列表

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 功能 A | P0 | 核心能力 |

### 3.2 用户故事

每个功能拆成用户故事,格式见 `USER_STORY_TEMPLATE.md`。

## 4. 非功能需求

- 性能(如:支持 1000 QPS,响应 < 200ms)
- 安全(如:敏感数据加密)
- 兼容 / 可维护性

## 5. 开放问题

| 问题 | 决策人 | 状态 |
|------|--------|------|
| 是否支持某场景 | 产品 | 待定 |
