# 五维安全扫描 Checklist

## 1. 代码安全
- [ ] SQL 注入(参数化查询)
- [ ] XSS(输出编码)
- [ ] 命令注入 / 反序列化

## 2. 认证
- [ ] 会话管理(失效 / 续期)
- [ ] 越权(IDOR:横向 / 纵向)
- [ ] 暴力破解防护(限流 / 锁定)

## 3. 数据
- [ ] 敏感数据加密(静态 / 传输)
- [ ] 脱敏(日志 / 返回)

## 4. 依赖
- [ ] 已知漏洞组件(版本扫描)
- [ ] 依赖版本锁定

## 5. 配置
- [ ] 密钥硬编码
- [ ] 默认口令 / 越权配置

## 严重度

| 级别 | 处理 |
|------|------|
| CRITICAL / HIGH | 硬阻断 |
| MEDIUM / LOW | 记录不阻断 |

## 产出

`scan_result:{ 维度, 严重度, 位置, 修复建议 }[]`
