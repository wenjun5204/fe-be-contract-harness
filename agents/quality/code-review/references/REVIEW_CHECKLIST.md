# 代码评审 Checklist

## 正确性(P0/P1)
- [ ] 边界条件(空 / 超长 / 并发)
- [ ] 错误处理(异常 / 降级)
- [ ] 事务边界 / 幂等

## 契约一致性(P1)
- [ ] 路由 / DTO 字段与契约一致(`python3 lib/contract/cli.py check <contract>`)
- [ ] 覆盖率 ≥ 60%

## 安全(P0)
- [ ] SQL 注入 / XSS / 越权 / 敏感数据泄露

## 可维护性(P2)
- [ ] 命名清晰 / 无重复 / 无死代码
- [ ] 生成区与人工区分离(不改「勿手改」文件)

## 严重度细则

| 级别 | 定义 | 处理 |
|------|------|------|
| P0 | 安全漏洞、数据损坏 | 必须修 |
| P1 | 正确性风险、覆盖率不达标、契约漂移 | 必须修 |
| P2 | 设计缺陷、可维护性 | 建议修 |
| Nit | 风格、命名 | 可选 |
