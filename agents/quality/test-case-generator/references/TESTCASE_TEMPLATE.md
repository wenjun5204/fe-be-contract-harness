# 测试用例模板

## 接口用例(从契约派生)

| 用例 ID | 端点 | 输入 | 预期状态码 | 预期响应 |
|---------|------|------|-----------|----------|
| TC-001 | GET /pets | 无 | 200 | Pet[] |
| TC-002 | POST /pets | 合法 body | 201 | Pet |
| TC-003 | POST /pets | 缺必填字段 | 400 | Error |

## 四维预期(每条用例覆盖)

1. **接口响应**:响应 schema 与契约一致
2. **DB 数据**:落库正确(字段 / 状态)
3. **日志**:关键操作有日志
4. **副作用**:消息 / 缓存 / 告警符合预期

## 前端用例

- 交互路径:正常 + 异常(加载失败 / 空数据 / 错误码)
- 接口 mock:用契约派生的 mock(MSW/Prism)
- 视觉回归:截图比对

## 派生规则(§14.8)

- 每个 `path` → 正常 / 边界 / 错误码用例
- 每个 `schema` 字段 → 必填 / 类型 / 枚举 / 长度边界
- `x-*` 幂等 / 分页 → 幂等重放 / 分页越界
